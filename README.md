# 🛒 Sistema de Desconto Progressivo

Um script simples em Python desenvolvido para calcular o valor final de uma compra aplicando regras de **desconto progressivo** com base no valor total gasto.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma ferramenta de linha de comando (CLI) que recebe o valor total de uma compra, verifica em qual faixa de desconto o cliente se enquadra e calcula automaticamente:
- A porcentagem de desconto concedida.
- O valor abatido em reais (R$).
- O valor final atualizado a pagar.
